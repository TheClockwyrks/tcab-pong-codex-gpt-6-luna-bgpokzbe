# Carom

Carom is a top-down paddle duel built with the Simple 2D engine. Rally through a pair of central gates, use paddle movement to add spin, and win by reaching eleven points with a two-point lead. Play solo against the computer or share the keyboard in local versus.

## Install and run

```sh
npm ci
npm run dev
```

Open the local URL printed by Vite. To produce the static production site in `dist/`, run:

```sh
npm run build
```

Serve `dist/` from the root of any static file server. The game has no backend or runtime asset downloads.

## Controls

- Player one: **W/S**
- Player two in Versus: **↑/↓**
- Menus: **↑/↓**, **Enter** or **Space**
- Pause/resume: **P** or **Escape**
- Mute: **M**
- Menus also respond to mouse and touch.
